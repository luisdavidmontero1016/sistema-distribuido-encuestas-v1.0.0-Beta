• 📊 Sistema Distribuido de Encuestas RPC

> Sistema distribuido de encuestas en tiempo real con arquitectura cliente-servidor (RPC), desarrollado en Java para la gestión concurrente y estadística de datos.

---

## • Características principales
- **Arquitectura Cliente-Servidor:** Comunicación eficiente mediante Llamadas a Procedimientos Remotos (RPC).
- **Gestión Concurrente:** Soporte para múltiples clientes interactuando con el servidor de forma simultánea.
- **Módulo de Encuestas:** Creación, distribución y procesamiento de respuestas automatizadas.
- **Análisis Estadístico:** Consolidación de resultados centralizada en el servidor.

---

## • Tecnologías y Estructura
* **Lenguaje:** Java
* **Estructura del proyecto:**
  * `cliente-encuestas/`: Módulo encargado de la interfaz y la interacción con el usuario final.
  * `servidor-encuestas/`: Núcleo de procesamiento, lógica de negocio y gestión de peticiones RPC.
